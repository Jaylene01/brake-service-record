# WEIDE Luxury Brake Service Record

Mobile-first web app for recording Brake Fluid / Brake Oil service records at WEIDE Luxury.

## Features

- Dashboard summary
- New service record form
- Internal Record No. for workshop lookup
- Customer and vehicle details
- Vehicle Brand / Make field
- Brake Fluid / Brake Oil replacement record
- Automatic next change date calculation
- Automatic next mileage calculation
- Service history search
- Customer electronic service record card
- WhatsApp sharing
- PDF / print through the browser print dialog
- Local browser storage

## Run

Open `index.html` directly in a browser, or serve the folder with any static file server.
